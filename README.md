# Bank Management System

A Java-based banking system that demonstrates object-oriented programming.

## Description

This program simulates a simple banking system where users can add customers, create savings and checking accounts, and perform deposits and withdrawals.

The program uses JOptionPane dialog boxes for user interaction.

## Features

- Add customers
- Create savings accounts
- Create checking accounts
- Deposit money
- Withdraw money
- View customer and account information
- Random customer and account number generation
- Object-oriented programming
- Input validation

## Technologies

- Java
- Java Swing (JOptionPane)
- ArrayList
- Object-Oriented Programming

## How to Run

1. Download or clone this repository.
2. Make sure all Java files are in the same project.
3. Compile `Client.java`.
4. Run the `Client` class.
5. Follow the instructions shown in the dialog boxes.
